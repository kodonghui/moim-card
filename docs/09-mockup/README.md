2026-11-28 · 상태: **확정, 토큰 고정**(DEC-035, 승인 버전 PR #10 커밋 `e03ce6f`) · 준비와 조건: [prep.md](prep.md)

- 방향(DEC-033): 사용자님 답(Orca 항목 256, e4535) "어느 시안으로 갈까요? → A 바탕 + 카드만 B(추천)". 시안 A 바탕(흰 바탕, 파란 버튼, TDS 배치)에 합의 카드만 시안 B의 카드 한 장 모양이에요. 주황·초록·회청색은 합의 카드 안에서만 써요.
- 방장 화면 버튼(DEC-034): 사용자님 답(같은 항목, e4535) "방장 화면 버튼 3개(저장·보내기·마감) 이대로 둘까요? → 이대로".
- 그 전 단계: 시안 두 개(DEC-031)의 캡처는 [captures/candidates/](../../design/mockups/captures/candidates/)에 남겼어요. 시안 페이지와 시안별 토큰 파일은 고른 방향 하나로 합치며 지웠어요(커밋 기록에 남아 있어요).

## 3. 사용자님께 드릴 최종 확인 질문

**질문 1. 이 목업으로 확정할까요?** — 답: 추천안 1(DEC-035, 오랑이가 사용자님 주말 위임으로 답함). 실제 토스 WebView·스크린 리더·키보드 순서는 개발 단계 확인 항목이에요 (확정하면 색·글자 크기·간격 같은 디자인 값을 고정하고, 개발은 이 목업과 08 화면 정의를 기준으로 해요. DDD 변경 아님)

1. 이대로 확정해요. **← 추천**
2. 고칠 화면이 있어요(화면 이름과 고칠 점을 알려 주세요).

- 추천 이유: 고르신 방향(A 바탕 + 카드만 B)과 방장 버튼 3개를 그대로 15개 화면 모든 상태에 그렸어요. 글자 대비·누르는 영역·한국어 줄바꿈 검사 292번에서 문제가 0개였고, 주황 카드 색은 합의 카드 밖에 쓰이지 않아요. 확정해야 다음 단계(작업 나누기, 개발)로 갈 수 있어요.
- 반대 근거: 실제 토스 앱 안에서 TDS 부품으로 그리면 버튼 모양·글꼴이 조금 달라 보일 수 있어요(토스 글꼴은 TDS 부품에만 들어가요). 또 휴대폰으로 직접 눌러 본 것이 아니라서, 개발 뒤 실제 기기에서 한 번 더 봐야 해요. 확정한 뒤에도 고칠 수는 있지만 결정을 하나 더 기록해야 해요.
