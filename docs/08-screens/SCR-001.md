# SCR-001 진입 확인

경로 `/` · 누가: 토스 앱 사용자 누구나(확인 전) · 흐름: FL-001, FL-003 · SPEC: SPEC-001, SPEC-002, SPEC-023, SPEC-035

목적: 미니앱을 열면 토스 앱 버전을 보고 로그인 없이 사용자를 확인한 뒤, 초대 링크면 방 소개(SCR-005)로, 아니면 홈(SCR-002)으로 보내요. (FL-001, FL-003)

## 데이터

| 데이터 | 출처 |
| --- | --- |
| 토스 앱 버전 | SDK(앱 정보). 읽지 못하면 낮은 버전으로 다뤄요(SPEC-001) |
| 인증 코드 | SDK `User.createAnonymousKeyAuthCode()`(SPEC-002). 화면에 보이지 않고 서버에만 보내요 |
| 세션 토큰 | API-001 응답 `sessionToken`. 메모리에만 두고 기기 밖에 남기지 않아요 |
| 초대 링크의 방 코드 | 진입 주소의 `room` 값. 읽은 뒤 주소에서 지우고 메모리에만 둬요(S-1) |
| 유입 경로 | `referrer` → API-016 `referrerKind`(SPEC-023) |

## 동작

| 동작 | 결과 | 실패 |
| --- | --- | --- |
| 미니앱 열기(자동) | 버전 확인 → API-001 → API-016 → 다음 화면. 다음 화면은 이 화면 기록을 바꿔 끼워요(S-2) | 낮은 버전 → #update-required. 확인 실패 → #error |
| [다시 시도] | 새 인증 코드를 받아 API-001을 다시 불러요 | 다시 실패하면 #error 그대로 |
| [닫기] | 미니앱을 닫아요 | 없음(SDK 닫기는 실패를 돌려주지 않아요) |

## 상태

| 상태 | 사용자가 보는 것과 할 수 있는 것 | 이 응답에서 |
| --- | --- | --- |
| SCR-001#loading | 화면 가운데 미니앱 이름(가칭)과 "확인하고 있어요". 버튼 없음. 1초 안에 끝나면 보이지 않아요(G-8) | API-001 요청 중 |
| SCR-001#update-required | "토스 앱을 업데이트하면 쓸 수 있어요"와 "앱스토어나 플레이스토어에서 토스를 업데이트해 주세요", [닫기]. 서버 요청은 0건이에요 | 버전 5.232.0 미만이거나 읽지 못함 |
| SCR-001#error | "확인하지 못했어요"와 [다시 시도]·[닫기]. 429면 "잠시 뒤 다시 해 주세요"와 남은 초(G-3), 그 밖의 실패는 오류 번호(G-4) | API-001#401, API-001#429, API-001#400, API-001#default, 시간 초과 |
| SCR-001#permission | "지금은 쓸 수 없어요"만 보이고 버튼 없음(G-2) | API-001#403 |

## 해당하지 않는 상태

- normal: 확인에 성공하면 이 화면은 보이지 않고 바로 다음 화면으로 가요.
- empty: 보여 줄 목록이 없어요.
- stale: 보여 주는 데이터가 없어요.

## 응답과 상태

| 응답 | 코드 | 상태 | 화면이 하는 일 |
| --- | --- | --- | --- |
| API-001#201 | started | 없음(다음 화면) | 토큰을 메모리에 두고 API-016을 보낸 뒤, 방 코드가 있으면 SCR-005, 없으면 SCR-002로 가요 |
| API-001#400 | invalid_request, validation_failed | error | G-5. [다시 시도]는 새 인증 코드로 해요 |
| API-001#401 | auth_failed | error | "확인하지 못했어요", [다시 시도](새 인증 코드)·[닫기] |
| API-001#403 | origin_not_allowed | permission | G-2 |
| API-001#429 | rate_limited | error | G-3 |
| API-001#default | internal, route_not_found, method_not_allowed | error | G-4 |
| API-016#204 | | 없음 | 아무것도 바꾸지 않아요 |
| API-016#400 | invalid_request, validation_failed | 없음 | 기록만 포기해요. 앱 버그로 오류 보고에 남겨요(G-5의 보고만) |
| API-016#401 | unauthenticated | 없음 | 기록만 포기해요(다시 보내지 않음, SPEC-023 [반복]) |
| API-016#403 | origin_not_allowed | 없음 | 기록만 포기해요. API-001이 이미 G-2를 보였어요 |
| API-016#429 | rate_limited | 없음 | 기록만 포기해요 |
| API-016#default | internal, route_not_found, method_not_allowed | 없음 | 기록만 포기해요. 진입을 막지 않아요 |

## 경우의 종류

| 종류 | 화면에 보이는 것 |
| --- | --- |
| 접근 | 확인 전에는 어떤 데이터도 읽거나 쓰지 않아요. 토스 앱 밖은 #permission |
| 반복 | 인증 코드는 한 번만 쓸 수 있어 [다시 시도]마다 새 코드를 받아요 |
| 한도 | #error의 429 모양(G-3) |
| 외부 | 토스 API 오류·시간 초과(5초)는 서버가 401 `auth_failed`로 돌려줘 #error |
| 노출 | 인증 코드·토큰·방 코드가 화면, 주소, 로그에 없어요 |
| 화면 상태 | 네 상태 모두 360px·430px 와이어프레임이 있어요 |
| 해당 없음 | 입력, 대상, 상태 변화, 동시성, 빈 결과, AI 답(이 앱은 AI를 부르지 않아요) |

## 규칙

- 진입 직후 바텀시트·알림 동의를 띄우지 않아요(REQ-066). 회원가입·실명·연락처를 묻지 않아요(SPEC-001).
- 첫 의미 있는 화면(SCR-002 또는 SCR-005)이 P95 10초 안에 보여야 해요(SPEC-036).
