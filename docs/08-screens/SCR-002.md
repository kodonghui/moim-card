# SCR-002 홈

경로 `/home` · 누가: 확인된 사용자 · 흐름: FL-001, FL-002, FL-011, FL-012, FL-015, FL-016 · SPEC: SPEC-039, SPEC-009

목적: 방을 새로 만들거나, 참여 중인 열린 방으로 돌아가거나, 지난 카드·내 데이터 지우기·약관으로 가요. (FL-001, FL-016)

## 데이터

| 데이터 | 출처 |
| --- | --- |
| 내 방 목록: 모임 이름, 테마 이름, 응답 완료 수/인원, 방장 표시, 내가 답했는지 | API-012 `rooms[]`(`gatheringName`, `theme.name`, `submittedCount`, `partySize`, `myRole`, `mySubmitted`) |
| 방 코드 | API-012 `rooms[].roomCode`. 화면에 보이지 않고, 고른 방을 SCR-005에 넘기는 데만 써요(DEC-025) |
| 기준 시각 | API-012 `asOf` |
| 메뉴(지난 카드, 내 데이터 지우기, 이용약관, 개인정보처리방침) | 번들 안 고정 문구 |

## 동작

| 동작 | 결과 | 실패 |
| --- | --- | --- |
| [방 만들기] | SCR-003으로 가요 | 없음(화면 이동만) |
| 방 하나 누름 | 그 방 코드를 메모리에 두고 SCR-005로 가요. SCR-005가 상태를 다시 보고 문항·카드·최종 카드로 보내요(SPEC-039) | SCR-005의 실패(없는 방 등)를 따라요 |
| [새로고침] | API-012를 다시 불러요 | #error의 목록 부분 |
| [지난 카드] | SCR-011로 가요 | 없음(화면 이동만) |
| [내 데이터 지우기] | SCR-013으로 가요 | 없음(화면 이동만) |
| [이용약관]·[개인정보처리방침] | SCR-014·SCR-015로 가요 | 없음(화면 이동만) |

## 상태

| 상태 | 사용자가 보는 것과 할 수 있는 것 | 이 응답에서 |
| --- | --- | --- |
| SCR-002#normal | 맨 위 [방 만들기](주 버튼). "참여 중인 방" 목록: 줄마다 모임 이름(두 줄까지), 테마 · "4명 중 3명 답했어요", 방장이면 "방장", 답하기 전이면 "답하기 전" 표시. 목록 아래 "오후 3시 5분 기준"과 [새로고침]. 맨 아래 메뉴 줄 4개 | API-012#200(`two-rooms`) |
| SCR-002#loading | [방 만들기]와 메뉴는 바로 보이고 쓸 수 있어요. 목록 자리에 회색 줄 2개(G-8) | API-012 요청 중 |
| SCR-002#empty | 목록 자리에 "참여 중인 방이 없어요"와 "방을 만들고 친구를 불러 보세요". [방 만들기]는 맨 위 그대로 | API-012#200(`empty`) |
| SCR-002#error | 목록 자리에 "잠시 뒤 다시 해 주세요"와 [다시 시도]. [방 만들기]·메뉴는 그대로 써요(G-4) | API-012#default, 시간 초과 |
| SCR-002#permission | 401은 화면 뒤에서 다시 확인(G-1), 토스 앱 밖이면 "지금은 쓸 수 없어요"(G-2) | API-012#401, API-012#403 |
| SCR-002#stale | 미니앱으로 돌아오면 목록을 다시 불러와요. 불러오는 동안 지난 목록을 그대로 두고 기준 시각 옆에 작은 진행 표시를 보여 줘요(G-9) | 다시 불러오기 |

## 해당하지 않는 상태

- 없음. 여섯 가지 모두 있어요.

## 응답과 상태

| 응답 | 코드 | 상태 | 화면이 하는 일 |
| --- | --- | --- | --- |
| API-012#200 | two-rooms, empty | normal 또는 empty | 방이 1개 이상이면 normal, 0개면 empty |
| API-012#401 | unauthenticated | permission | G-1 |
| API-012#403 | origin_not_allowed | permission | G-2 |
| API-012#default | internal, route_not_found, method_not_allowed | error | G-4(목록 부분만) |

## 경우의 종류

| 종류 | 화면에 보이는 것 |
| --- | --- |
| 접근 | 내가 참여자인 열린 방만 와요(서버가 걸러요). 확인 안 됨은 G-1 |
| 상태 변화 | 목록을 본 뒤 방이 마감·만료될 수 있어요. 누르면 SCR-005가 다시 보고 최종 카드나 없는 방 안내로 보내요 |
| 한도 | 목록은 최대 20개(SPEC-039). 더 보기 없음 |
| 외부 | 목록 실패는 목록 부분만 #error이고 [방 만들기]·메뉴는 써요 |
| 노출 | 닉네임, 누가 답했는지, 방 코드가 화면에 없어요 |
| 빈 결과 | #empty |
| 화면 상태 | 20자 모임 이름은 360px에서 두 줄. 여섯 상태 모두 360px·430px 와이어프레임 |
| 해당 없음 | 입력, 반복(읽기만 함), 동시성, AI 답 |

## 규칙

- 홈은 초대 링크 없이 들어온 첫 화면이라 뒤로가기는 미니앱을 닫아요(SPEC-009).
- 목록 순서는 최근 입장 순이에요(SPEC-039).
