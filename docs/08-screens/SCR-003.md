# SCR-003 테마 고르기

경로 `/rooms/new` · 누가: 확인된 사용자 · 흐름: FL-002, FL-009 · SPEC: SPEC-004

목적: 방장이 될 사용자가 배포된 테마 중 하나를 골라 방 정보 적기(SCR-004)로 가요. 최종 카드의 [우리도 해 보기]도 여기로 와요. (FL-002, FL-009)

## 데이터

| 데이터 | 출처 |
| --- | --- |
| 테마 이름, 문항 세트 버전 | API-002 `themes[]`(`themeId`, `name`, `questionSetVersion`). 버전은 화면에 보이지 않아요 |

## 동작

| 동작 | 결과 | 실패 |
| --- | --- | --- |
| 테마 하나 누름 | 고른 테마를 메모리에 두고 SCR-004로 가요 | 없음(화면 이동만). 배포가 그사이 내려간 테마는 SCR-004의 409에서 다뤄요 |
| [다시 시도] | API-002를 다시 불러요 | #error 그대로 |

## 상태

| 상태 | 사용자가 보는 것과 할 수 있는 것 | 이 응답에서 |
| --- | --- | --- |
| SCR-003#normal | 제목 "어떤 모임인가요?", 테마 줄(여행, 회식·저녁, 주말 나들이). 줄 하나가 44pt 이상 | API-002#200(`three-themes`) |
| SCR-003#loading | 제목과 회색 줄 3개(G-8) | API-002 요청 중 |
| SCR-003#empty | "지금은 만들 수 있는 테마가 없어요". 고를 줄이 없어 방을 만들 수 없어요(SPEC-004) | API-002#200(`empty`) |
| SCR-003#error | "잠시 뒤 다시 해 주세요"와 [다시 시도](G-4) | API-002#default, 시간 초과 |
| SCR-003#permission | G-1, G-2 | API-002#401, API-002#403 |

## 해당하지 않는 상태

- stale: 테마 목록은 화면을 열 때마다 불러오고, 그사이 내려간 테마는 SCR-004가 409 `theme_unavailable`로 받아 이 화면으로 돌아와 다시 불러와요.

## 응답과 상태

| 응답 | 코드 | 상태 | 화면이 하는 일 |
| --- | --- | --- | --- |
| API-002#200 | three-themes, empty | normal 또는 empty | 테마가 1개 이상이면 normal, 0개면 empty |
| API-002#401 | unauthenticated | permission | G-1 |
| API-002#403 | origin_not_allowed | permission | G-2 |
| API-002#default | internal, route_not_found, method_not_allowed | error | G-4 |

## 경우의 종류

| 종류 | 화면에 보이는 것 |
| --- | --- |
| 접근 | 확인된 사용자 누구나. 확인 안 됨은 G-1 |
| 상태 변화 | 배포가 내려간 테마는 SCR-004에서 "이 테마는 지금 쓸 수 없어요" 뒤 여기서 다시 불러와요 |
| 외부 | #error |
| 빈 결과 | #empty |
| 화면 상태 | 다섯 상태 모두 360px·430px 와이어프레임 |
| 해당 없음 | 입력, 대상, 반복, 동시성, 한도(읽기는 세지 않음), 노출(공개 테마 이름만), AI 답 |

## 규칙

- 배포된 테마만 보여 줘요(REQ-037). 테마 이름은 최대 20자예요.

## 목업

- 목업: [design/mockups/mockup.html](../../design/mockups/mockup.html)에서 SCR-003 화면을 고르면 상태가 모두 나와요(09, DEC-033). 토큰은 [design/base.tokens.json](../../design/base.tokens.json)이에요.
- 제목 아래 "테마마다 문항 8개가 정해져 있어요". #empty에 "테마가 준비되면 여기에 보여요"를 더해요.
