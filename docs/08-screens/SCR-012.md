# SCR-012 지난 카드 자세히

경로 `/past-cards/:pastCardId` · 누가: 확인된 사용자(자기 지난 카드만) · 흐름: FL-011 · SPEC: SPEC-027

목적: 지난 카드 요약 하나의 문항 8개 분류와 문구, 다음 행동을 끝까지 봐요. (FL-011)

## 데이터

| 데이터 | 출처 |
| --- | --- |
| 요약 전체: 모임 이름, 테마 이름, 기준 응답 수, 확정일, 다음 행동, 문항 8개(분류·수·문구) | SCR-011이 받은 API-013 `pastCards[]`의 한 항목(메모리). 새 요청이 없어요(S-7) |

## 동작

| 동작 | 결과 | 실패 |
| --- | --- | --- |
| 화면 열기 | 메모리의 요약을 보여 줘요 | 메모리에 없음(미니앱을 다시 연 경우) → #error |
| [지난 카드 목록으로](#error에서만) | SCR-011로 가요 | 없음(화면 이동만) |

## 상태

| 상태 | 사용자가 보는 것과 할 수 있는 것 | 이 응답에서 |
| --- | --- | --- |
| SCR-012#normal | 모임 이름, 테마 · "11월 28일 · 3명 기준", 다음 행동 한 줄(강조), 분류 세 그룹과 문항마다 수·문구. 버튼 없음(읽기만) | |
| SCR-012#error | "지난 카드를 다시 불러와 주세요"와 [지난 카드 목록으로] | 메모리에 요약 없음 |

## 해당하지 않는 상태

- loading: 요청이 없어 기다릴 것이 없어요.
- empty: 지난 카드는 늘 문항 8개가 있어요(API-013 `items` 8개).
- permission: SCR-011이 이미 내 것만 받아 왔어요. 세션이 끝나도 이 화면은 새 요청을 하지 않아요.
- stale: 확정된 요약은 바뀌지 않아요.

## 응답과 상태

이 화면은 API를 부르지 않아요. SCR-011의 API-013 응답을 써요.

## 경우의 종류

| 종류 | 화면에 보이는 것 |
| --- | --- |
| 노출 | 닉네임·방 코드 없음 |
| 화면 상태 | 두 상태 모두 360px·430px 와이어프레임 |
| 해당 없음 | 접근(SCR-011에서), 입력, 대상, 상태 변화, 반복, 동시성, 한도, 외부, 빈 결과, AI 답 |

## 규칙

- 경로의 `pastCardId`는 서버의 번호(정수)이고 방 코드가 아니에요.
