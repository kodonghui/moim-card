# SCR-005 방 소개

경로 `/room` · 누가: 방 코드를 가진 확인된 사용자(초대 링크 또는 내 방 목록) · 흐름: FL-003, FL-016 · SPEC: SPEC-006, SPEC-009, SPEC-039

목적: 방 코드로 방 상태를 보고, 처음 온 사람에게는 방 소개와 [참여하기]를, 이미 참여자나 마감된 방이면 알맞은 화면을 보여 줘요. (FL-003, FL-016)

## 데이터

| 데이터 | 출처 |
| --- | --- |
| 모임 이름, 테마, 인원, 응답 완료 수, 상태(열림·마감), 8명인지 | API-004 `RoomView`(`gatheringName`, `theme.name`, `partySize`, `submittedCount`, `status`, `isFull`) |
| 내 참여: 역할, 답했는지 | API-004 `myRole`, `mySubmitted` |
| 기준 시각 | API-004 `asOf` |
| 방 코드 | SCR-001(초대 링크) 또는 SCR-002(내 방 목록)가 메모리에 둔 값. 없으면 SCR-002로 보내요 |

## 동작

| 동작 | 결과 | 실패 |
| --- | --- | --- |
| 화면 열기(자동) | API-004 → 갈 곳 정하기(아래 규칙). 다른 화면으로 갈 때는 이 화면 기록을 바꿔 끼워요(S-3) | #error, #permission |
| [참여하기] | SCR-006으로 가요 | 없음(화면 이동만). 입장 때 서버가 상태를 다시 봐요 |
| [방 만들기] | SCR-003으로 가요 | 없음(화면 이동만) |
| [새로고침] | API-004를 다시 불러요 | #error |

## 상태

| 상태 | 사용자가 보는 것과 할 수 있는 것 | 이 응답에서 |
| --- | --- | --- |
| SCR-005#normal | 모임 이름(두 줄까지), 테마, "인원 4명 · 3명 답했어요", "응답 받는 중", "인원이 다 답하면 마감돼요", "오후 3시 5분 기준". 맨 아래 [참여하기] | API-004#200(`open-newcomer`) |
| SCR-005#loading | 같은 배치에 회색 자리 표시. 버튼 없음(G-8) | API-004 요청 중 |
| SCR-005#full | 모임 이름과 "이 방은 8명이 다 찼어요". [참여하기] 대신 [방 만들기] | API-004#200(`open-full`) |
| SCR-005#error | 404: "이 방은 없거나 보관 기간이 지났어요"와 [방 만들기]. 그 밖: G-4 | API-004#404, API-004#default, 시간 초과 |
| SCR-005#permission | G-1, G-2 | API-004#401, API-004#403 |
| SCR-005#stale | 미니앱으로 돌아오면 다시 불러와요(G-9). 그사이 마감됐으면 SCR-010, 8명이 찼으면 #full로 바뀌어요 | 다시 불러오기 |

## 해당하지 않는 상태

- empty: 방이 있으면 보여 줄 소개가 늘 있고, 없으면 404(#error)예요.

## 응답과 상태

| 응답 | 코드 | 상태 | 화면이 하는 일 |
| --- | --- | --- | --- |
| API-004#200 | open-newcomer, open-full, open-host, closed | normal, full 또는 다음 화면 | `status: closed` → SCR-010. `myRole`이 member·host이고 `mySubmitted: false` → SCR-007. `mySubmitted: true` → 초대 링크로 왔으면 SCR-008(FL-003), 내 방 목록에서 왔으면 SCR-009(SPEC-039). `myRole: none`이고 `isFull` → #full. 그 밖 → #normal |
| API-004#401 | unauthenticated | permission | G-1 |
| API-004#403 | origin_not_allowed | permission | G-2 |
| API-004#404 | room_not_found | error | "이 방은 없거나 보관 기간이 지났어요", [방 만들기](C-5: 형식이 틀린 코드·만료된 방도 같음) |
| API-004#default | internal, route_not_found, method_not_allowed | error | G-4 |

## 경우의 종류

| 종류 | 화면에 보이는 것 |
| --- | --- |
| 접근 | 참여자가 아니어도 방 소개는 보여요. 이미 참여자면 새로 만들지 않고 내 화면으로(REQ-006) |
| 대상 | 없는·만료된 방 → #error 404 |
| 상태 변화 | 8명이 참 → #full, 마감 → SCR-010. 입장 때 서버가 다시 봐요(SCR-006) |
| 외부 | G-4 |
| 노출 | 닉네임, 누가 답했는지, 참여자 수(8명인지만), 방 코드가 화면에 없어요(SPEC-006, R-11) |
| 화면 상태 | 여섯 상태 모두 360px·430px 와이어프레임 |
| 해당 없음 | 입력, 반복(읽기만 함), 동시성(SCR-006), 한도(읽기는 세지 않음), 빈 결과, AI 답 |

## 규칙

- 초대 링크로 들어와 이 화면이 첫 화면이면 뒤로가기는 미니앱을 닫아요(REQ-056).
- "인원이 다 답하면 마감돼요"는 늘 보여요(REQ-055).

- #full에 "우리 모임 방을 새로 만들 수 있어요"를 더해요.
