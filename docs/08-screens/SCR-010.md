# SCR-010 최종 카드

경로 `/room/final` · 누가: 마감된 방의 방 코드를 가진 확인된 사용자 누구나. 카드 저장·단톡방에 보내기는 응답한 참여자만 · 흐름: FL-003, FL-004, FL-006, FL-007, FL-008, FL-009 · SPEC: SPEC-021, SPEC-019, SPEC-020, SPEC-022, SPEC-009

목적: 마감된 방의 최종 카드를 누구나 읽기 전용으로 보고, [우리도 해 보기]로 우리 모임 방을 만들어요. 응답한 참여자는 저장·공유도 해요. (FL-009, FL-006)

## 데이터

| 데이터 | 출처 |
| --- | --- |
| 최종 카드: 기준 응답 수, 문항마다 분류·수·문구, 다음 행동, 확정 시각 | API-009 `Card`(`stage: final` 또는 `none`, `finalizedAt`). 방장 마감 직후면 SCR-009가 받은 API-010 응답의 `card`(메모리) |
| 모임 이름, 테마, 내가 답했는지 | API-004 `gatheringName`, `theme.name`, `mySubmitted` |
| 카드 이미지 | SDK `File.saveBase64`(SPEC-020) |
| 초대 링크 | SDK `Share.createLink`(SPEC-022) |

## 동작

| 동작 | 결과 | 실패 |
| --- | --- | --- |
| [우리도 해 보기] | SCR-003으로 가요(REQ-082) | 없음(화면 이동만) |
| [카드 저장](응답한 참여자) | 기기에 PNG 저장, "저장했어요" | "저장하지 못했어요"와 [다시 시도] |
| [단톡방에 보내기](응답한 참여자) | 초대 링크로 토스 공유 시트. 마감된 방의 링크는 이 화면으로 이어져요 | "링크를 만들지 못했어요"와 [다시 시도]. 낮은 버전 → G-10 |
| [내 모임 성향 다시 보기](응답한 참여자) | SCR-008로 가요(W-7) | 없음(화면 이동만) |

## 상태

| 상태 | 사용자가 보는 것과 할 수 있는 것 | 이 응답에서 |
| --- | --- | --- |
| SCR-010#normal | 모임 이름, 테마, "마감됐어요 · 3명 기준 · 11월 28일 확정". 다음 행동 한 줄(강조), 분류 세 그룹과 문항마다 수·문구. 맨 아래 [우리도 해 보기](주 버튼). 응답한 참여자에게는 그 위에 [카드 저장], [단톡방에 보내기], [내 모임 성향 다시 보기]. 입장·응답 버튼 없음 | API-009#200(`final`), API-004#200(`closed`) |
| SCR-010#loading | 같은 배치에 회색 자리 표시(G-8) | API-009 요청 중 |
| SCR-010#empty | "답한 사람이 적어 카드 없이 마감됐어요"와 [우리도 해 보기] | API-009#200(`closed-without-card`) |
| SCR-010#error | 404: "이 방은 없거나 보관 기간이 지났어요"와 [방 만들기]. 그 밖: G-4. 저장·링크 실패는 그 버튼 아래 안내 | API-009#404, API-009#default, API-004#404, API-004#default |
| SCR-010#permission | G-1, G-2. 마감된 방은 누구나 보므로 403 `not_participant`·`response_required`는 오지 않아야 해요. 오면 SCR-005로 보내 다시 봐요 | API-009#401, API-009#403, API-004#401, API-004#403 |

## 해당하지 않는 상태

- stale: 최종 카드는 확정 뒤 바뀌지 않아요(SPEC-015). 보는 동안 보관 기간이 지나면 다음에 열 때 404(#error)예요.

## 응답과 상태

| 응답 | 코드 | 상태 | 화면이 하는 일 |
| --- | --- | --- | --- |
| API-009#200 | final, closed-without-card, interim, one-response | normal 또는 empty | `final` → normal. `none` → empty. `interim`·`one-response`(열린 방) → SCR-005로 보내 다시 봐요 |
| API-009#401 | unauthenticated | permission | G-1 |
| API-009#403 | not_participant, response_required, origin_not_allowed | permission | `origin_not_allowed` → G-2. 나머지 둘은 열린 방이라는 뜻이라 SCR-005로 |
| API-009#404 | room_not_found | error | 없는 방 안내와 [방 만들기] |
| API-009#default | internal, route_not_found, method_not_allowed | error | G-4 |
| API-004#200 | closed, open-host, open-newcomer, open-full | normal | `mySubmitted`로 응답한 참여자 버튼을 정해요. 열린 방이면 SCR-005로 |
| API-004#401 | unauthenticated | permission | G-1 |
| API-004#403 | origin_not_allowed | permission | G-2 |
| API-004#404 | room_not_found | error | 없는 방 안내와 [방 만들기] |
| API-004#default | internal, route_not_found, method_not_allowed | error | G-4 |

## 경우의 종류

| 종류 | 화면에 보이는 것 |
| --- | --- |
| 접근 | 마감 뒤에는 응답하지 않은 사람과 처음 온 사람도 봐요(DEC-013). 저장·공유는 응답한 참여자만 |
| 대상 | 만료된 방 → 404 안내 |
| 상태 변화 | 없음(확정된 카드는 바뀌지 않음) |
| 외부 | 저장·공유 실패는 그 버튼 아래 안내만 |
| 노출 | 모임 이름·테마·카드만. 닉네임, 누가 답했는지, 방 코드가 없어요(SPEC-021) |
| 빈 결과 | #empty |
| 화면 상태 | 다섯 상태 모두 360px·430px 와이어프레임 |
| 해당 없음 | 입력, 반복(읽기만 함, 저장은 SCR-009와 같음), 동시성, 한도, AI 답 |

## 규칙

- 초대 링크로 들어와 이 화면이 첫 화면이면 뒤로가기는 미니앱을 닫아요(REQ-056).
