# SCR-004 방 정보 적기

경로 `/rooms/new/details` · 누가: 확인된 사용자(테마를 고른 뒤) · 흐름: FL-002 · SPEC: SPEC-005, SPEC-008

목적: 모임 이름, 인원, 내 닉네임을 적어 방을 만들고 문항(SCR-007)으로 가요. (FL-002)

## 데이터

| 데이터 | 출처 |
| --- | --- |
| 고른 테마 이름 | SCR-003에서 넘긴 API-002 결과(메모리). 없으면(미니앱을 다시 연 경우) SCR-003으로 보내요 |
| 만든 방: 방 코드, 모임 이름, 인원, 테마 | API-003 응답 `CreatedRoom`. 방 코드는 메모리에만 둬요 |
| 금칙어 목록 | 번들 안 목록(SPEC-008, 서버와 같은 규칙) |

## 동작

| 동작 | 결과 | 실패 |
| --- | --- | --- |
| 칸에 적기 | 모임 이름 "3/20"처럼 남은 글자 수, 인원은 2~8 중 고르기(기본 4), 닉네임 "0/10". 칸을 떠날 때 화면이 규칙을 봐요 | 규칙 밖 → 칸 아래 이유(#error), 값은 그대로 |
| [방 만들기] | API-003(요청 ID 함께) → 성공하면 SCR-007로 가요. 기록은 홈 → 문항이 되어 뒤로가기가 이 화면으로 돌아오지 않아요(S-5) | 400 칸별 이유, 409 테마 없음, 429·오류는 다시 시도(#error) |

## 상태

| 상태 | 사용자가 보는 것과 할 수 있는 것 | 이 응답에서 |
| --- | --- | --- |
| SCR-004#normal | 맨 위 고른 테마 이름. 칸 3개(모임 이름, 인원, 내 닉네임)와 닉네임 칸 아래 "닉네임은 이 방에서 나만 봐요". 맨 아래 [방 만들기]는 세 칸이 규칙에 맞을 때 켜져요 | |
| SCR-004#loading | [방 만들기]에 진행 표시, 칸과 버튼이 꺼져요(G-7) | API-003 요청 중 |
| SCR-004#error | 400: 칸마다 이유("모임 이름은 1~20자로 적어 주세요", "인원은 2~8명이에요", "닉네임은 1~10자로, 쓸 수 없는 말이 있어요"), 적은 값 그대로. 409 테마: "이 테마는 지금 쓸 수 없어요"와 [테마 다시 고르기]. 그 밖: G-3·G-4 | API-003#400, API-003#409, API-003#429, API-003#default |
| SCR-004#permission | G-1(적은 값 그대로 두고 다시 확인 뒤 같은 요청 ID로 다시 보냄), G-2 | API-003#401, API-003#403 |

## 해당하지 않는 상태

- empty: 적는 화면이라 빈 목록이 없어요.
- stale: 서버 데이터를 보여 주지 않아요. 테마가 그사이 내려가면 #error의 409예요.

## 응답과 상태

| 응답 | 코드 | 상태 | 화면이 하는 일 |
| --- | --- | --- | --- |
| API-003#201 | created | 없음(다음 화면) | 방 코드를 메모리에 두고 SCR-007로 가요 |
| API-003#400 | validation_failed, invalid_request | error | `validation_failed`는 `errors[].field`의 칸 아래 이유. `invalid_request`는 G-5 |
| API-003#401 | unauthenticated | permission | G-1 |
| API-003#403 | origin_not_allowed | permission | G-2 |
| API-003#409 | theme_unavailable, idempotency_conflict | error | `theme_unavailable`: 안내 뒤 [테마 다시 고르기] → SCR-003에서 다시 불러와요. `idempotency_conflict`: G-6 |
| API-003#429 | rate_limited | error | G-3(하루 30개 한도도 같은 모양) |
| API-003#default | internal, route_not_found, method_not_allowed | error | G-4. 적은 값 그대로, 다시 시도는 같은 요청 ID |

## 경우의 종류

| 종류 | 화면에 보이는 것 |
| --- | --- |
| 입력 | 칸 아래 이유, 적은 값 그대로. 앞뒤 공백은 지운 뒤 세요. 줄바꿈·제어 문자는 받지 않아요 |
| 대상 | 내려간 테마 → 409 안내와 [테마 다시 고르기] |
| 반복 | 버튼이 꺼져 한 번만 보내고, 시간 초과 뒤 다시 보내도 방은 하나(같은 요청 ID, SPEC-005) |
| 한도 | G-3 |
| 외부 | G-4, 적은 값 그대로 |
| 노출 | 응답에는 방 코드·모임 이름·인원·테마만 와요. 방 코드는 화면에 없어요 |
| 화면 상태 | 키보드가 올라와도 [방 만들기]가 키보드 위에 보여요. 네 상태 모두 360px·430px 와이어프레임 |
| 해당 없음 | 동시성(내 방 하나만 만듦), 빈 결과, AI 답 |

## 규칙

- 모임 이름 1~20자, 인원 2~8, 닉네임 1~10자·금칙어 없음(SPEC-005, SPEC-008). 화면과 서버가 같은 규칙으로 봐요.
