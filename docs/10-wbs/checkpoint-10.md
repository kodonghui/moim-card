# 10 WBS 체크포인트 질문

상태: **답 기다림**(2026-11-28) · 대상: [wbs.md](wbs.md)(TASK-001~054, U-1~U-10, B-1~B-10) · 이 PR의 커밋이 승인 대상이에요.

이 체크포인트는 "다음 개발 계획에 합의하나"예요(10 단계 계약). 계획이 통과되기 전에는 어떤 TASK도 시작하지 않아요. 앞 단계(09 목업)의 통과는 이 계획을 승인하지 않아요.

## 1. 앞 단계 승인에서 빠지거나 바뀐 것

**없어요.** 이 WBS는 승인된 요구사항·흐름·SPEC 행을 빼거나 미루거나 뜻을 바꾸지 않아요. `scripts/check-wbs.py`로 SPEC 39행, REQ 84개, API operation 16개, 화면 15개가 모두 TASK에 닿는 것을 확인했어요. 열린 채로 가져가는 것은 이미 기록된 미확인 사실(F-1, F-3)과 개발 단계 확인 항목 3개(DEC-035)뿐이고, 어느 TASK에 있는지는 [wbs.md 4절](wbs.md#4-개발-단계-확인-항목과-미확인-사실)에 있어요.

## 2. 질문

### 질문 1. 이 계획으로 개발을 시작할까요?

- **추천안 1(추천)**: TASK-001~054와 순서(페이즈 0 → 페이즈 1·2 같이 → 페이즈 3), AI가 정한 B-1~B-10을 승인하고, 첫 개발 페이즈(페이즈 0, TASK-001~012)를 시작해요. 페이즈 0에는 외부 계정·콘솔·사용자님 일이 없어요.
- 다른 방법 2: 페이즈 0만 승인하고, 페이즈 1~3은 페이즈 0이 끝난 뒤 다시 봐요.
- 다른 방법 3: 화면 먼저(페이즈 2를 페이즈 1보다 앞에). 목 서버가 있어 가능하지만, 서버 규칙(동시성·마감)이 늦게 검증돼요.
- **반대 근거**: TASK 54개를 한 번에 승인하면, 페이즈 0을 하면서 알게 된 것(예: Workers 풀에서 D1 batch의 동작, TDS 버전 호환)이 뒤 TASK의 크기나 순서를 바꿀 수 있어요. 그래도 크기·순서 변경은 이 파일을 고치는 일이고 요구사항을 바꾸지 않아, 다시 승인받을 일은 아니라고 봤어요. 요구사항·SPEC이 바뀌는 일이 나오면 변경 절차로 따로 여쭤요.

### 질문 2. 사용자님께 제품명(appName)과 토스 콘솔 앱 등록(U-1·U-2)을 언제 여쭐까요?

배경: appName은 콘솔에 등록하면 바꿀 수 없고 실서비스 주소와 공유 링크에 들어가요. 미확인 F-1(사업자 없이 mTLS 인증서가 발급되나)은 앱을 등록해야 확인할 수 있고, 안 되면 사용자 확인(SPEC-002)과 알림(SPEC-025) 설계를 다시 봐야 해요. 페이즈 0~2는 가짜 토스 서버와 목 서버로 하므로 U-1·U-2 없이 진행돼요.

- **추천안 1(추천)**: 페이즈 0을 시작하면서 바로 여쭤요. F-1을 가장 일찍 확인해, 안 되면 서버 TASK(013·031·032)를 만들기 전에 설계를 고칠 수 있어요.
- 다른 방법 2: 페이즈 1·2가 끝나 TASK-050을 시작하기 직전에 여쭤요. 그동안 제품명을 더 고민할 수 있어요.
- **반대 근거**: 제품명이 아직 '가칭'이라, 일찍 여쭈면 이름을 서둘러 정하게 되고 appName이 영원히 고정돼요. 또 F-1이 안 되더라도 바뀌는 것은 토스 API 클라이언트(TASK-010)와 그 위 몇 TASK뿐이라, 늦게 알아도 버리는 일은 크지 않을 수 있어요.

## 3. NEXUS 체크포인트 요청 문안

병합과 push 뒤 NEXUS 10 단계에 단계 전체 댓글(`--asks checkpoint --look-first stage`)로 올릴 문안이에요. NEXUS는 병합 전에는 이 초안을 보여 주지 않아요.

```text
10 WBS: 개발 계획을 TASK 54개로 나눴어요.
먼저 볼 것: 이 단계의 TASK 목록
- 페이즈 0(TASK-001~012)부터 시작해요. 외부 계정·콘솔이 필요 없어요.
- 서버 operation 16개와 화면 15개가 TASK마다 PR 하나로 나뉘어요.
- 사용자님 일 10개(U-1~U-10)를 따로 적었어요. 제품명은 아직 가칭이에요.
- 첫 번째로 필요한 것은 U-1 제품명(appName)과 U-2 콘솔 앱 등록이에요.
- 사업자등록은 첫 버전에 필요 없어요(광고·결제 없음).
이 계획으로 개발을 시작해도 될까요?
```
